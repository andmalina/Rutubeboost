# Rutube Boost

Живое продвижение видео на [rutube.ru](https://rutube.ru). Игроки смотрят ролики от 20 секунд, ставят лайки, пишут комментарии и подписываются на каналы. Чтобы опубликовать своё — нужно закрыть три чужих задания в той же категории.

**1 своё через 3 чужих.**

## Как это работает

| Категория | Что делает игрок | Как выйти в эфир |
| --- | --- | --- |
| Просмотры | Смотрит ролик ≥ 20 сек | 3 просмотра |
| Лайки | Ставит лайк на Rutube | 3 лайка |
| Комментарии | Оставляет комментарий | 3 комментария |
| Подписки | Подписывается на канал | 3 подписки |

Публикация — по ссылке на видео `rutube.ru`. В студии живой чат для всех игроков.

## Запуск

```bash
npm install
npm start
```

Сервер слушает `0.0.0.0:3000`. Данные пишутся в `data/db.json`.

Не является официальным сервисом RUTUBE.
